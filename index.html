Coding agents mostly reason by acting.

Today's coding agents can edit files, run tests, and execute commands. What they lack is an internal model of how software systems evolve.

Local edits

Agents often optimize the next edit without modeling the long-term repository state.

Execution-first loops

They discover consequences after editing, testing, failing, and retrying.

Missing dynamics

Software evolution may have structure that can be learned, predicted, and planned over.

The core hypothesis

Given a repository state and a desired goal, future software states may be predicted before changes are executed.

state_t + goal → state_t+1

Rather than predicting only tokens, model future repository states.

Latent rollout demo

A software world model could simulate possible future states in latent space, then let an agent choose a better plan before touching the codebase.

Research areas

SocietasLabs investigates whether software systems exhibit learnable dynamics that can be modeled similarly to physical environments.

Latent representations

Repositories, architectures, and code states represented in latent space.

Code evolution

Modeling how codebases change across sequential software edits.

Agent planning

Planning in latent space before execution and code modification.

Self-supervised learning

Learning software structure without direct token reconstruction.

Architecture reasoning

Reasoning beyond individual files, functions, and short context windows.

Future state rollout

Simulating multi-step trajectories toward a desired software goal.

Long-term goal

Build software world models that allow AI systems to reason about software in the same way world models allow agents to reason about physical environments.

The goal is not to build another coding agent. The goal is to understand whether software systems have learnable dynamics that can be represented, predicted, and eventually planned before execution.
