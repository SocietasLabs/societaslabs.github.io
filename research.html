Research note 001

Early evidence for latent software dynamics.

We started with a controlled synthetic code-evolution world to test a simple question: can a model learn how software moves through latent space across sequential edits?

Interpretation

The baseline accumulates error as future states are predicted. The JEPA-style architecture remains close to the target latent manifold, suggesting that software evolution may contain learnable latent dynamics.

Controlled launchpad

Before moving to LLM-generated code evolution, we use deterministic synthetic transforms as a control condition. This makes failure modes visible and keeps the latent dynamics measurable.

Synthetic before → after code transitions across reliability, security, observability, performance, maintainability, and API evolution.

02

Code transitions are checked with parsing, compilation, and optional lint-style filters.

03

Before states, after states, and change goals are mapped into latent space.

04

Models predict future latent states across multiple sequential edits.

05

Drift, clustering, branch behavior, and rollout stability are inspected.

Two model tracks

The research currently compares a small direction baseline against a dual-encoder JEPA-style model.

DirectionHead baseline

A small model that predicts a normalized direction vector from a before-code embedding and a change description. It remains useful as a sanity check because transform directions cluster cleanly by type.

DualEncoderJEPA

A context encoder observes masked code views while a stable target encoder observes clean views. A predictor aligns latent targets and a rollout head learns how software states move across edits.

The interesting result is not that the model predicts code tokens. It does not. The interesting result is that latent rollout can remain stable while plain multi-step rollout drifts.

What comes next

The next step is to turn this research into a small public demo: a latent code map that shows how a proposed change moves a repository toward or away from a goal.

Research direction

The long-term goal is to understand whether software systems have learnable dynamics that can be represented, predicted, and eventually planned before execution.
